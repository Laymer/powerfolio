Navzeroth

Azeroth Navigator — a desktop companion for World of Warcraft: Forever

Development prerelease · v1.0.0-rc.1 ↗

Navzeroth brings imported character snapshots, planning, an atlas and session review into a desktop application. It connects my interest in distributed systems, careful data handling and software that people can inspect and run locally.

Rust architecture

A modular Rust workspace separates core logic, ingestion, storage, local-data processing and command-line tools. A Tauri desktop shell connects to a React interface and SQLite storage; a Lua addon supplies explicitly exported snapshots.

Local data & privacy

Imported profiles remain local. File selection and imports are explicit, and imported Lua is treated as data. The desktop works from snapshots, with no game-memory access or input automation.

Development practice

I use agentic coding and prompt engineering to turn requirements into scoped implementation work, then review changes and verify behaviour through tests. The project is also my current hands-on learning environment for Rust.

Early community interest

The project has attracted offers to contribute, shared datasets and interest in alpha testing. Complete game-content coverage and full live-game and Windows validation remain work in progress.
